# Plantilla gratis de revisión semanal para Obsidian (en español)

Dos plantillas de Obsidian en español para ordenar tu negocio con 30 minutos por semana:

- **Revisión semanal**: una lista en cinco pasos (vaciar, mirar números, revisar proyectos, anotar aprendizajes y elegir el foco) con tablas listas para completar.
- **Nota diaria**: tres prioridades, registro del día y un cierre con lo que avanzó de verdad.
- **Una nota de inicio** que explica cómo usarlas, y la configuración de Obsidian ya preparada para las dos plantillas.

## Cómo usarla

1. Descargá Obsidian gratis desde [obsidian.md](https://obsidian.md).
2. Descargá esta carpeta (botón **Code → Download ZIP**) o el [zip del sitio](https://yabianskysempire.github.io/fundador/descargas/plantilla-revision-semanal-gratis.zip), y abrí la carpeta `Revision semanal del fundador` como bóveda.
3. Activá los plugins **Plantillas** y **Notas diarias**, que ya vienen con Obsidian.

Guía completa: [Plantilla gratis de revisión semanal](https://yabianskysempire.github.io/fundador/plantilla-revision-semanal-gratis.html).
